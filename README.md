# FlowForge — SaaS Landing + Pricing + Free Trial Onboarding

Live Demo: https://senthilkumarks1362004-eng.github.io/flowforge-saas/

A polished, production-ready marketing landing page for a SaaS product. Built to demonstrate high-converting freelance skills — landing pages are top-requested on Contra / Upwork / Fiverr.

### Features
- Hero with animated dashboard mockup
- Features grid, How it works, Testimonials
- Pricing: Starter $19, Pro $49 (Popular), Enterprise Custom with Monthly/Yearly toggle
- Free Trial Onboarding Flow (4 steps: Email → Qualification → Team Size → Success)
- FAQ accordion, Footer CTA
- Fully Responsive + Scroll animations

### Stack
HTML5, Tailwind CSS, Vanilla JavaScript
